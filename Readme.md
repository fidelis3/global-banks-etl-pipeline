# Global Banks ETL Project

## Project Overview

This project implements an ETL pipeline in Python to collect market capitalization data for the world's largest banks, transform the values into multiple currencies, and load the results into both CSV and SQLite outputs.

Data source used for extraction:
- Web archive snapshot of Wikipedia's list of largest banks.

## Workflow

The pipeline in banks_project.py follows these stages:

1. Extract
- Scrapes bank names and market capitalization in USD (billions).

2. Transform
- Reads exchange rates from exchange_rate.csv.
- Adds:
	- MC_GBP_Billion
	- MC_EUR_Billion
	- MC_INR_Billion
- Rounds converted values to 2 decimal places.

3. Load
- Writes transformed data to largest_banks.csv.
- Loads/replaces table Largest_banks in SQLite database Banks.db.

4. Logging
- Appends timestamped progress messages to etl_project_log.txt.

## Project Structure

- banks_project.py: Main ETL script.
- exchange_rate.csv: Currency conversion rates used in transformation.
- largest_banks.csv: Output CSV generated by the pipeline.
- etl_project_log.txt: ETL execution logs.
- Readme.md: Project documentation.

From the project folder, run:
